## 🚀 Öne Çıkan Özellikler

* **📱 %100 Duyarlı (Responsive) Tasarım:** Sitenin arayüzü; mobil, tablet ve masaüstü cihazlara kusursuz uyum sağlayacak şekilde CSS Flexbox ve Grid sistemleriyle inşa edilmiştir[.
* **✨ Dinamik UI/UX Etkileşimleri:** Sayfa kaydırıldıkça tetiklenen yumuşak geçiş animasyonları (Intersection Observer API) ve şık hover efektleri kullanılmıştır.
* **🎨 Özel CSS Mimarisi:** CSS Değişkenleri (Custom Properties) kullanılarak renk paleti (Nav-dark, Accent, vb.) ve tasarım tutarlılığı tek bir merkezden yönetilmiştir.
* **📅 Etkileşimli Bileşenler:** JavaScript ile yönetilen etkinlik detay modalları ve asenkron form gönderim simülasyonları entegre edilmiştir.

## 🛠️ Kullanılan Teknolojiler ve Araçlar

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Tipografi:** Google Fonts (Playfair Display, Cormorant Garamond, Poppins, Inter, DM Sans)
* **İkonografi:** FontAwesome 6.0

## 📁 Proje Mimarisi (Sayfalar)

Proje, birbirine entegre 6 farklı modüler HTML sayfasından oluşmaktadır:

1. `index.html` - Dinamik slider ve öne çıkan özelliklerin sergilendiği Karşılama Ekranı
2. `menu.html` - Ürün kategorilerinin listelendiği kapsamlı menü arayüzü
3. `hakkimda.html` - Kafenin vizyonu, hikayesi ve görsel galeri alanı[
4. `etkinlikler.html` - Workshopların ve sanat takviminin yer aldığı dinamik sayfa
5. `iletisim.html` - İletişim formu, sosyal medya bağlantıları ve Google Maps entegrasyonu
6. `oyun.html` - Müşteriler için geliştirilmiş interaktif şans oyunu arayüzü
